# 从邮箱导入发票 · 使用与部署说明

「从邮箱导入」通过自建 Cloudflare Worker 连接 163 / 126 / yeah / QQ 邮箱（IMAP，端口 993），按日期范围搜索发票邮件（滴滴、华住、12306 等），勾选后自动下载其中的 PDF / ZIP 附件并汇入导入列表。本文覆盖授权码开通、后端部署、安全说明与常见问题。

## 功能概览

- 支持服务商：网易 163 / 126 / yeah 邮箱与 QQ 邮箱（服务端主机白名单，不接受任意地址）。
- 时间范围：起始日期 + 结束日期两个日期选择器，结束日含当日；默认近 30 天，**最长跨度 90 天**（前端与服务端双重校验）。
- 关键词过滤：**可选，默认留空（不过滤，列出全部含附件的邮件）**；填写后按逗号分隔，任一关键词命中即保留，匹配范围为主题、发件人与附件文件名（英文引号内为短语，如 `"电子 发票"`）。过滤在浏览器本地完成（IMAP 中文主题搜索编码不可靠）。
- 附件：提取邮件中的 PDF 与 ZIP（ZIP 再解出其中的 PDF，如 12306 发票包），走与本地导入完全相同的去重、页数上限、渲染链路。
- 结果预筛：**服务端**在搜索时按邮件结构（BODYSTRUCTURE）判断，只返回含 PDF/ZIP 附件的邮件，无附件的通知类邮件不会占用返回额度。
- 页面内可查看：对话框顶部「授权码获取与设置说明」含各邮箱开通路径与常见提示；完整文档（含部署）随站点发布在 `docs/mail-import.md`。
- 每封邮件独立请求，单封失败不影响其余；成功导入后凭据过期时间自动顺延。

## 开通客户端授权码

邮箱要求使用「客户端授权码」登录第三方客户端，**不是登录密码**。以下为常见入口（页面可能随改版微调，以邮箱内实际为准）：

| 邮箱 | 入口 | 说明 |
| --- | --- | --- |
| 163 | 设置 → POP3/SMTP/IMAP → 开启 IMAP/SMTP 服务 | 开启时需短信验证，得到一串授权码 |
| 126 / yeah | 设置 → POP3/SMTP/IMAP → 开启 IMAP/SMTP 服务 | 同网易系流程 |
| QQ 邮箱 | 设置 → 账户 → POP3/IMAP/SMTP/Exchange/CardDAV/CalDAV 服务 → 开启 IMAP/SMTP | 开启后按提示短信验证生成授权码 |

注意：

- 请确认 IMAP 服务为**开启**状态，否则即使授权码正确也会登录失败。
- 授权码可随时在上述页面吊销并重新生成，吊销后旧码立即失效。

## 部署后端（Cloudflare Worker）

后端为单个 Cloudflare Worker，同时托管静态前端与 IMAP 中继 API，免费版配额（10 万请求/天）足够个人使用。

1. 安装依赖：`npm.cmd install`
2. 登录 Cloudflare：`npx.cmd wrangler login`（浏览器授权）
3. 构建并部署：`npm.cmd run deploy`（等价于 `vite build && wrangler deploy`）
4. 部署完成后得到 `https://<项目名>.<账号>.workers.dev`，打开即可使用。

自动化：在 Cloudflare 控制台把 Worker 连接到 GitHub 仓库（该 Worker 的 Settings → Builds → Connect），推送 `main` 即自动构建部署；构建命令填 `npm run check`，部署命令填 `npx wrangler deploy -c worker/wrangler.toml`，无需在 GitHub 配置 Secret。

本地联调：直接 `npm.cmd run dev`（同时启动前端热更新与 Worker，`/api` 已代理）；或先 `npm.cmd run build` 再 `npm.cmd run dev:api`，访问 `http://localhost:8787`（产物模式，同时提供前端与 API）。

### 可选环境变量

| 变量 | 作用 | 设置方式 |
| --- | --- | --- |
| `API_TOKEN` | 设置后所有 `/api/*` 请求必须携带 `Authorization: Bearer <token>`，防止公开部署被滥用 | 推荐 `npx wrangler secret put API_TOKEN`；设置后在前端对话框「高级设置 → 访问令牌」填同一值 |
| `ALLOW_ORIGIN` | 前后端分域部署时的 CORS 放行来源（如 `https://example.com`） | `worker/wrangler.toml` 的 `[vars]` 或 secret；分域时前端「高级设置 → API 地址」填 Worker 完整地址（`https://…/api`） |

同源部署（`wrangler deploy` 后前端与 API 同域）无需设置任何变量。

## 安全说明

- **授权码仅保存在本机浏览器 localStorage**（键前缀 `mi-mail.*`），默认 60 天过期，每次成功搜索或导入自动顺延 60 天；对话框展示过期时间并提供「清除已存授权码」按钮。清空浏览器缓存即全部消失。
- **Worker 侧零存储**：不使用 KV/D1 等任何存储，凭据只存在于单次请求的内存中，不落盘、不打印日志。
- 授权码泄露风险可控：可在邮箱设置页随时吊销并重新生成；建议不要在公共电脑上勾选使用。
- 服务端仅暴露两个固定语义端点（搜索邮件头、取单封原始邮件），IMAP 主机硬编码白名单，无法被当作任意 IMAP 跳板。

## 本地存储行为一览

| 键 | 内容 | 过期 |
| --- | --- | --- |
| `mi-mail.cred.<服务商>` | 授权码与账号（`{v, email, code, expiresAt}`） | 60 天，成功使用即顺延；过期仅清授权码、保留账号占位 |
| `mi-mail.keywords` | 关键词字符串 | 永不过期 |
| `mi-mail.ui` | 起止日期、服务商、API 地址、访问令牌 | 永不过期 |

## 常见问题

| 现象 | 原因与处理 |
| --- | --- |
| 提示「未检测到邮箱后端服务（HTTP 404）」 | 纯静态托管未部署 Worker，按上文部署后重试 |
| 提示「授权码错误或 IMAP 服务未开启」 | 核对授权码是否复制完整；确认邮箱 IMAP 服务已开启；必要时吊销重取 |
| 提示「邮箱判定当前登录环境不安全（Unsafe Login）」 | 网易系要求第三方客户端登录后先发 IMAP ID 声明身份，否则拒绝收信（Worker 已自动发送）；若仍出现，按提示在网页版邮箱查看安全提醒放行，或稍后重试 |
| 提示「无法保持 IMAP 连接」「IMAP 操作超时」 | 网络或邮箱服务端临时问题，稍后重试；时间范围过大时先缩小范围 |
| 搜索结果里没有目标邮件 | 扩大日期范围；清空或调整关键词（关键词同时匹配主题与发件人） |
| 某封邮件提示「没有 PDF/ZIP 附件」 | 该邮件本身不含发票附件，属正常情况 |
| 频繁搜索后被邮箱拒绝登录 | 163/QQ 对异地登录有风控，稍后再试或在邮箱端检查登录记录 |

## 相关限制

- 单次搜索默认返回最近 200 封含 PDF/ZIP 附件的邮件（上限 500 封）；服务端最多检查范围内最新的 1000 封候选，更早的邮件请缩小起始日期分批搜索。
- 单个 PDF 最多 10 页（与本地导入一致），超出会被拒绝。
- 不支持 Gmail / Outlook（需 OAuth2，暂未实现）。
